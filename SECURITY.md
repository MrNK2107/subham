# Security

## Reporting a vulnerability

Please open a private security advisory on this repository rather than a public issue.

## Threat model

| Threat                                 | Control                                                                                                                                                                                                                                                                                                                                                                       | Where                                                                                                                |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Leaked AI credentials                  | `GEMINI_API_KEY` is read only by server route handlers. On Cloud Run it comes from Secret Manager. `.env*` files are git-ignored.                                                                                                                                                                                                                                             | [`gemini.ts`](src/ai/gemini.ts), [`provider.ts`](src/ai/provider.ts)                                                 |
| Cross-site scripting                   | Per-request nonce CSP with `strict-dynamic`; no `unsafe-inline`/`unsafe-eval` in production; React escapes text; no inline `style` attributes anywhere, so styles need no exemption either.                                                                                                                                                                                   | [`proxy.ts`](src/proxy.ts), [`csp.ts`](src/server/csp.ts)                                                            |
| Clickjacking, MIME sniffing, downgrade | `frame-ancestors 'none'`, `X-Frame-Options: DENY`, `nosniff`, HSTS with preload, `upgrade-insecure-requests`, strict `Referrer-Policy`, minimal `Permissions-Policy`.                                                                                                                                                                                                         | [`next.config.ts`](next.config.ts)                                                                                   |
| Malformed or oversized requests        | Every API route requires `application/json`, caps the body (64 KB; 400 KB for the assistant, which receives the plan), and validates with zod before doing any work. Errors name the field, never internals.                                                                                                                                                                  | [`guard.ts`](src/server/guard.ts), [`schemas.ts`](src/server/schemas.ts)                                             |
| Abuse and quota exhaustion             | Per-client fixed-window limits on every AI route, plus a 30-minute cache for identical requests and a hard time budget per AI call.                                                                                                                                                                                                                                           | [`throttle.ts`](src/server/throttle.ts), [`memo.ts`](src/server/memo.ts)                                             |
| Prompt injection                       | User data is wrapped in tagged blocks with `<` escaped, so it can't close the block; instructions refer to fields by name and never inline user text. System prompts treat tagged content as data only. Output must match a schema. Tool calls are allow-listed, re-validated, filtered to those that apply to the real plan, and **applied only after the person approves**. | [`prompts.ts`](src/ai/prompts.ts), [`tools.ts`](src/ai/tools.ts), [`/api/assistant`](src/app/api/assistant/route.ts) |
| Untrusted model output                 | `cleanBlueprint` keeps only items that validate; `withFallbacks` replaces thin sections; `assemblePlan` and `applyChange` re-validate the whole plan with zod.                                                                                                                                                                                                                | [`assemble.ts`](src/core/assemble.ts), [`changes.ts`](src/core/changes.ts)                                           |
| Reading or editing someone's plan      | Firestore rules: owner has full control; editors (verified email listed by the owner) may change `data` only; viewers read only; everyone else is denied; document keys, types and list sizes are checked. Tested on the emulator.                                                                                                                                            | [`firestore.rules`](firestore.rules), [`rules/plans.test.ts`](rules/plans.test.ts)                                   |
| Tampered local storage                 | Plans loaded from `localStorage` are validated with zod; invalid entries are skipped.                                                                                                                                                                                                                                                                                         | [`local.ts`](src/store/local.ts)                                                                                     |
| Private details in URLs                | The landing-page description reaches the wizard through `sessionStorage`, never the URL.                                                                                                                                                                                                                                                                                      | [`prefill.ts`](src/ui/wizard/prefill.ts)                                                                             |
| Vulnerable dependencies                | CI runs `npm audit --omit=dev --audit-level=high` (0 vulnerabilities). A patched `@grpc/grpc-js` is pinned through `overrides`.                                                                                                                                                                                                                                               | [`ci.yml`](.github/workflows/ci.yml), [`package.json`](package.json)                                                 |
| Container hardening                    | Multi-stage build, standalone output only, runs as a non-root user.                                                                                                                                                                                                                                                                                                           | [`Dockerfile`](Dockerfile)                                                                                           |

## Notes

- The Firebase web config (`NEXT_PUBLIC_FIREBASE_*`) is public by design; access is enforced by the rules.
- Rate limits are kept in memory per instance and keyed on the **last** `X-Forwarded-For` entry, the one
  Google's front end appends; anything a client puts earlier in the header is ignored. A shared store (Memorystore) would make them global if abuse ever required it.
  `RATE_LIMIT_SCALE` raises the limits for the end-to-end suite, which runs from a single address.
