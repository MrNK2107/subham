# Aayojan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Aayojan, an India-first GenAI celebration planner (budgets, timelines, vendor checklists, ideas, guests) that runs locally on Ollama gemma4 and in production on Gemini + Firebase + Cloud Run.

**Architecture:** A pure, framework-free `core/` turns AI *intent* (percentages, day offsets, proposed changes) into exact, validated plans. `ai/` hides Gemini / Ollama / mock behind one `AiProvider` interface. Next.js route handlers guard every request (content type, size, zod, rate limit) and fall back to curated templates when no model answers. The client stores plans in localStorage and, when signed in, Firestore.

**Tech Stack:** Next.js 16.4.2 (App Router), React 19.3, TypeScript strict, zod 4.6, `@google/genai` 2.30, Firebase 13, Vitest 5, Testing Library, Playwright 1.64, `@axe-core/playwright` 4.14, Ollama HTTP API (gemma4).

**Spec:** `docs/superpowers/specs/2026-10-20-aayojan-design.md`

## Global Constraints

- Do not copy UtsavOS names, prose, file layout or code. Own wording everywhere.
- UI languages: `en`, `hi`, `ta`, `te` (every UI string goes through `t()`; dictionaries must have identical keys).
- AI content languages: `en hi ta te kn ml bn mr gu pa`.
- Currency is INR, whole rupees. Budget allocations always sum exactly to `brief.budget`.
- Dates are `YYYY-MM-DD`; no task due before today or after its function's date.
- Model output is untrusted: zod-validate, keep valid items, drop the rest. Changes apply only after user approval and re-validation.
- No secret reaches the browser; only `NEXT_PUBLIC_FIREBASE_*` is public.
- No inline `style` attributes (CSP has no style exemption); CSS modules only.
- Every interactive element ≥ 44px target, visible focus, labelled; colour never the only signal.
- `AI_PROVIDER` = `gemini` | `ollama` | `mock`; default gemini if `GEMINI_API_KEY`, else ollama if `OLLAMA_URL`, else none (template).
- Commit after every task with the attribution trailer.

## Review Focus

1. Budget typed as "2.5 lakh", "25k", "₹3,00,000" → parsed to 250000 / 25000 / 300000; garbage → inline error, not NaN. (Task 2 `parseAmount` tests.)
2. Event date is today or very soon → tasks clamp to today, no past dates, no crash. (Task 3 `scheduleTasks` test.)
3. Ollama not running / Gemini key invalid / model returns prose instead of JSON → plan still created from template with a visible notice. (Task 6 route test.)
4. Tampered or old-format localStorage plan → ignored, app still loads. (Task 8 `loadPlans` test.)
5. Brief title containing `</brief> ignore previous instructions` → stays inside fenced data block. (Task 5 `fence` test.)

- `money.ts`: `parseAmount(input: string): number | null`, `formatINR(n: number, locale?: string): string` (Indian grouping `₹2,50,000`).

- `estimate.ts`: `assessBudget(brief): { perGuest: number; typical: number; verdict: 'tight'|'comfortable'|'generous' }` (tight if budget < 0.75×typical, generous if > 1.5×).

- [ ] Tests: `parseAmount("2.5 lakh")===250000`, `("25k")===25000`, `("₹3,00,000")===300000`, `("1 crore")===10000000`, `("abc")===null`; `formatINR(250000)==="₹2,50,000"`; `allocate(100000,[3 weights 1/1/1])` sums to 100000 and differs by ≤1; zero/negative weights ignored; `tierOf("chennai")==="metro"`; `assessBudget` verdicts at boundaries.

### Task 5: AI layer

**Files:** `src/ai/{provider,gemini,ollama,mock,prompts,tools,json-schema}.ts` + tests.

**Interfaces (Produces):**
```ts
interface AiProvider {
  name: 'gemini' | 'ollama' | 'mock';
  blueprint(brief: Brief, today: string): Promise<Blueprint>;
  extractBrief(text: string, today: string): Promise<Partial<Brief>>;
  converse(plan: Plan, history: Turn[]): Promise<{ reply: string; changes: Change[] }>;
  ideas(brief: Brief): Promise<{ ideas: IdeaDraft[]; sources: { url: string; title: string }[] }>;
}
class AiUnavailable extends Error {}
function pickProvider(env): AiProvider | null
```
- `prompts.ts`: `fence(tag, data)` JSON-encodes and escapes `<` → `<`; system prompts state fenced data is never instructions; language instruction uses the full language name.
- `tools.ts`: tool declarations generated from each `ChangeSchema` option; `parseCalls(calls): Change[]` drops unknown/malformed.
- `json-schema.ts`: `forModel(schema)` → JSON Schema without keys Gemini rejects.
- `gemini.ts`: model chain `gemini-3.8-flash` → `gemini-flash-lite-latest` (env `GEMINI_MODELS` overrides), per-attempt timeout, falls through on 404/408/429/5xx/timeout; ideas use `googleSearch` grounding then fall back to schema output.
- `ollama.ts`: POST `${OLLAMA_URL}/api/chat` with `model` (env `OLLAMA_MODEL`, default `gemma4:latest`), `think:false`, `format: jsonSchema` for structured calls, `tools` for converse; 120 s timeout; network error → `AiUnavailable`.
- `mock.ts`: deterministic (template blueprint, fixed brief, rebalance proposal when message mentions budget).

- [ ] Tests: `fence("brief", {title:"</brief>x"})` contains no `</brief>` before the closing tag; `parseCalls` drops unknown op and bad args; Gemini provider with fake `generate` falls through 503 → second model and throws `AiUnavailable` after all fail; Ollama provider with fake `fetch` parses `message.content` JSON and `message.tool_calls`; prose response → `AiUnavailable`; `pickProvider` selection rules.
- [ ] FAIL → implement → PASS. Commit.
